# Quick Start

This fork runs three coordinated services with Docker Compose:

- `stremio-libtorrent-server` — Stremio streaming engine and HTTPS endpoint;
- `webadmin` — administration UI on port `8090`;
- `pihole` — internal DNS service, with its web UI on port `8053` by default.

The current server release is tracked by `SERVER_VERSION` / `FORK_VERSION` and the core package version by `pyproject.toml`.

## 1. Prepare the environment

A safe operational `.env` baseline is versioned in this repository. Review it before starting, especially the LAN address:

```bash
nano .env
```

The default baseline currently uses:

```env
IPADDRESS=192.168.1.254
STREMIOSRV_LIBRARY_UI=true
STREMIOSRV_LIBRARY_ALLOW_HTTP=false
STREMIOSRV_LIBRARY_ADDON_ALLOW=192.168.1.0/24
```

Change `IPADDRESS` and the addon CIDR if your LAN uses another network.

Do not store passwords, API tokens, private keys or certificates in the versioned `.env`. Use a local override or Docker secrets for sensitive values.

## 2. Start the stack

```bash
docker compose config
docker compose up -d --build --force-recreate
docker compose ps
```

Do not use `docker compose down -v` during upgrades unless you intentionally want to delete persistent volumes.

## 3. Access the services

With the default `IPADDRESS=192.168.1.254`:

| Service | Address |
| --- | --- |
| Web Player | `http://192.168.1.254:8080` |
| WebAdmin | `http://192.168.1.254:8090` |
| Streaming API | `http://192.168.1.254:11470` |
| HTTPS / Stremio endpoint | `https://192.168.1.254:12470` |
| Pi-hole Web | `http://192.168.1.254:8053/admin/` |

The Compose file binds published ports to `IPADDRESS`. Therefore, when `IPADDRESS` is set to a specific LAN address, `127.0.0.1:<port>` on the Docker host is not expected to answer those published ports.

For trusted TV/client HTTPS, use the Stremio HTTPS URL/certificate generated by the server or your own certificate configuration.

## 4. Cache / Library Addon

The Library addon is enabled by default in the versioned `.env` and `compose.yaml`.

Open:

```text
https://<server>:12470/library/
```

After signing in with the owning Stremio account, use the **Watch this library in Stremio** panel to copy the generated addon manifest URL and install it in Stremio.

The addon exposes:

- a `My Library` catalog containing content already present on the server;
- local streams for recognised cached movies/episodes;
- automatic learning of `IMDb/Stremio ID ↔ cached torrent` from playback reports, without exposing file names in logs.

The addon remains protected by its per-install token and `STREMIOSRV_LIBRARY_ADDON_ALLOW` network policy.

## 5. Validate the server

Validate through the host address configured in `.env`:

```bash
set -a
. ./.env
set +a
curl -fsS "http://${IPADDRESS}:11470/health"
curl -fsS "http://${IPADDRESS}:11470/stats.json" | python3 -m json.tool
```

To test the process directly inside the container, independent of host port binding:

```bash
docker exec stremio-libtorrent-server curl -fsS http://127.0.0.1:11470/health
```

If the host-address request fails, inspect:

```bash
docker compose ps
ss -lntp | grep 11470 || true
docker compose logs --tail=200 stremio-libtorrent-server
```

For Library learning diagnostics, look under `playback` for:

```text
librarySubtitlesAsks
librarySubtitlesReports
libraryLabelsLearned
```

## 6. Pi-hole LAN DNS (optional)

The base `compose.yaml` does not bind DNS port 53 on the host. To expose Pi-hole DNS to the LAN:

```bash
docker compose -f compose.yaml -f compose.dns.yaml up -d
```

Review `PIHOLE_DNS_BIND_IP` and ensure host port 53 is available first.

## 7. VAAPI (optional)

Use the provided VAAPI compose override when the host exposes `/dev/dri` and hardware acceleration is required. The default `.env` keeps the fork's VAAPI-oriented transcoding policy while retaining software fallback.
